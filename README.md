# SHI Lab / xijunshi.com

Static academic website prepared for GitHub Pages.

## Preview locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a new public GitHub repository (for example `xijunshi-site`).
2. Upload all files and folders in this package to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide a `github.io` web address.

## Connect xijunshi.com
After you own the domain:
1. In GitHub **Settings → Pages**, enter `xijunshi.com` under Custom domain.
2. Follow GitHub's DNS instructions at your domain registrar.
3. Enable **Enforce HTTPS** when available.

Do not add a CNAME file until the domain is actually registered/configured.
